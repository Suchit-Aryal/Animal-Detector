# Presentation outline (5 slides, ~5 min). All numbers from results/comparison.csv, results/experiments.csv.

## Slide 1: Problem and goal (30 s)
- Stray and free-roaming animals (dogs, goats, cows, cats) on streets, with Nepal as the motivating context (cows and goats are common on roads in the Terai).
- Goal: fine-tune a small YOLO detector and show where a pretrained model is not enough; add a surveillance website that logs animals and ignores people.
- Honest scope note: the only test data so far is Open Images, not Nepal street footage.

## Slide 2: Pipeline (60 s)
- Image or video frame -> YOLO animal model (`yolov8s`, 4 evaluated classes + sheep) -> boxes, class, confidence.
- Website (Flask): a second model (COCO yolov8n) finds people; animal boxes that overlap a person are suppressed; people are counted separately and never logged as animals; animals go to a SQLite log with time, class, confidence, source and snapshot (per-class dedupe, default 10 s).
- Settings in `web/config.json`: animal confidence 0.5, person confidence 0.25.

## Slide 3: Why this approach (60 s)
- Transfer learning: start from COCO-pretrained Ultralytics YOLO weights, adapt to our classes. Small model = fast training (11.1M parameters for yolov8s, about 80-100 FPS (measured 78 and 98 on two runs) on an RTX 4050 laptop GPU).
- Experiments (one change per run, picked by validation mAP50, never by test): yolov8n 50 ep, yolov8s 80 ep, yolov8m 80 ep, yolov8s 80 ep with `freeze=10` (first 10 layers frozen).
- Figure: `results/figures/loss_curves.png`.

## Slide 4: Dataset and training setup (45 s)
- Dataset v2 images: train 2993 / val 634 / test 80 (frozen, same as v1) / test_extra 80 (held-out Open Images goat and sheep, 116 sheep boxes). Boxes: train 4787 (dog 337, goat 1109, cow 1808, cat 467, sheep 1066), val 947 (dog 52, goat 300, cow 318, cat 55, sheep 222), test 118 (dog 33, goat 22, cow 41, cat 22), test_extra 298 (dog 4, goat 108, cow 70, sheep 116).
- Sources: Open Images V7 (human-drawn boxes; split by image into train/val/test) + Mendeley street-animals photos (689 train-only images whose boxes were generated by a pretrained detector, not by people).
- Training: seed 0, imgsz 640, batch 8, patience 20, Ultralytics default augmentation (mosaic, flip, HSV), RTX 4050. yolov8s freeze=10 took 750 s.

## Slide 5: Results and limits (90 s + 30 s)
Test set (80 Open Images images, 118 boxes):

| Model | mAP50 | mAP50-95 | Precision | Recall | FPS |
|---|---|---|---|---|---|
| COCO yolov8n (baseline; no goat class) | 0.810 | 0.643 | 0.799 | 0.705 | 115 |
| Open Images V7 yolov8m (baseline) | 0.906 | 0.765 | 0.794 | 0.885 | 56 |
| Ours v2: yolov8s freeze=10, dataset v2 | 0.842 | 0.589 | 0.803 | 0.763 | 98 |
| (Ours v1, 1247-image dataset, for reference) | 0.854 | 0.577 | 0.851 | 0.808 | 78 |

- Per-class AP50 (dog / goat / cow / cat): ours v2 0.810 / 0.847 / 0.779 / 0.931 (v1: 0.818 / 0.842 / 0.811 / 0.945); COCO 0.795 / n/a / 0.725 / 0.908; OIV7 0.940 / 0.847 / 0.840 / 0.995.
- Within our own experiments, freeze=10 was clearly best on the v1 data (val mAP50 0.792 vs 0.603 / 0.663 / 0.635 for the other three runs). On v2 data, variant A (all boxes) reached val mAP50 0.773 vs 0.767 for variant B (without whole-frame Mendeley boxes): a tie, A chosen.
- Sheep and goat, test_extra (80 images, 116 sheep boxes, 108 goat boxes): v2 sheep AP50 0.711, goat 0.674; v1 model sheep 0.268, goat 0.561; OIV7 baseline sheep 0.767, goat 0.726; COCO sheep 0.717. Overall test_extra mAP50: v2 0.354, v1 0.218, OIV7 0.415, COCO 0.258 (dog and cow have only 4 and 70 boxes there; dog AP 0.0, cow 0.033 for v2: not meaningful as a score for those classes).
- Failure cases (`results/failure_cases.md`): dog predicted as goat at 0.94, missed goats in a crowd, a cow predicted where no animal is labelled.
- Figures: `comparison_bar.png`, `per_class_ap.png`, `confusion_matrix_test.png`.

### Honest caveats (say these out loud)
1. Test set = 80 Open Images images, not Nepal data. The numbers show the pipeline works, not that it works on Nepali streets.
2. The OIV7 baseline was pretrained on Open Images, so its 0.906 is probably inflated on this test set. We beat COCO on mAP50, precision and recall, but not on mAP50-95, and we are below OIV7.
3. Sheep: the frozen test has no sheep. Sheep is evaluated only on test_extra (116 boxes from 80 Open Images images); v2 sheep AP50 0.711 is below the OIV7 baseline 0.767.
4. Small test set (118 boxes; goat only 22), so per-class AP is noisy and differences of a few points mean little.
5. 689 of the training images carry model-generated boxes (from yolov8m-oiv7), so part of our training signal comes from a pretrained model's own opinion.
6. Still overfitting: v2 class loss is 0.38 on train vs 1.02 on val (v1 freeze=10: 0.30 vs 1.09; unfrozen yolov8s: 0.36 vs 1.50).
7. FPS measured on one laptop GPU (RTX 4050), single image at a time.
